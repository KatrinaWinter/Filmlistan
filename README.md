# Serielistan

En Android-app utvecklad med Kotlin och Jetpack Compose.

## Om appen
Serielistan är en app där användaren kan samla och hålla
ordning på sina favoritserier.

## Teknik
- Kotlin
- Jetpack Compose
- Android Studio

## Funktioner
- Visa en lista med TV-serier
- Visa information om varje serie
